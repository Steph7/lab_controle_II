# Laboratório de Controle II

Todos os arquivos foram desenvolvidos no Matlab. Eles foram separados de acordo com as práticas a que se referem. Dentro de cada uma delas há a Parte I, que se refere à coleta de dados da planta e a parte II que se refere à coleta de dados realizada após a implementação de um controlador desenvolvido pelo grupo.

Os arquivos foram nomeados com os prefixos a1, a2, a3, a4 para indicar que a ordem de compilação pode ser importante para que tudo funcione corretamente. 

Uma observação importante é que caso sejam realizadas novas coletas de dados é importante verificar a ordem na qual os dados estão sendo armazenadas, para que o código consiga processar os dados corretamente. Além de que deve-se conferir se o nome do arquivo confere com o arquivo processado pelo programa.
